# Wanderlust - Creative Travel Website

A stunning, responsive, and modern travel website landing page built with HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features

- **Modern Design**: Glassmorphism effects, elegant typography (Playfair Display), and a sophisticated color palette.
- **Responsive**: Fully optimized for desktops, tablets, and mobile devices.
- **Smooth Animations**: 
    - "Reveal on scroll" animations for content cards and text.
    - Smooth scrolling for navigation links.
    - Animated sticky navbar that changes style on scroll.
- **Interactive Elements**: Functional mobile hamburger menu and contact form (demo mode).

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, and advanced transitions.
- **JavaScript (Vanilla)**: Intersection Observer concept for scroll reveals and DOM manipulation.
- **Google Fonts**: Playfair Display & Poppins.
- **Unsplash API**: High-quality placeholder imagery.

## 🚀 Setup & Usage

1. **Clone the repository** (or download the ZIP).
2. **Open the project**:
   Simply double-click `index.html` to open it in any modern web browser (Chrome, Firefox, Safari, or Edge).

*Note: No web server or installation (like npm) is required for this static site.*
